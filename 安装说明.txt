并答 · 多模型答题助手 2.0
另一台 Windows 电脑 / Edge 安装说明

一、安装
1. 从 https://github.com/NINIFM/edge-answer-hub/releases/latest 下载 bingda-edge.zip，右键选择“全部解压缩”。建议解压到一个固定目录。
2. 打开 Edge，在地址栏输入 edge://extensions。
3. 开启“开发人员模式”，点击“加载解压缩的扩展”。
4. 选择解压目录里的 extension 文件夹。加载后请保留该文件夹，不要移走或删除。
5. 从 Edge 工具栏的扩展菜单点击“并答 · 多模型答题助手”，可将图标固定到工具栏。
6. 面板右上角应显示“版本2.0”。已有安装更新后，在 edge://extensions 点击本扩展的重新加载，再刷新面板；下一次发送会自动更新旧版模型网页；Kimi 会自动移除，阶跃星辰与腾讯混元会加入模型列表，已有启用和投票设置保留。

二、一键更新
1. 每台电脑首次双击安装目录中的“更新并答.cmd”，为当前 Windows 用户启用面板的更新启动入口，并检查最新版。不需要管理员权限。
2. 以后在面板右上角点击“一键更新”。Edge 若询问是否打开本地应用，选择打开。
3. 工具自动从 GitHub 检查版本、下载并替换原安装文件。当前已是最新版时不重复下载；下载或校验失败时保留原文件，替换失败时恢复已替换的文件。
4. 完成后在 edge://extensions 点击并答的“重新加载”，再刷新面板；下一次发送会自动更新旧版模型网页。
5. 首次从 1.0 升级，需要先将新版 ZIP 中的文件放入原安装目录，以取得按钮和更新工具。不要更改原 extension 目录的位置；移动整个目录后须重新双击“更新并答.cmd”启用入口。
6. 更新前先结束当前题目。更新不迁移或清空模型登录、浏览器设置。也可以直接双击“更新并答.cmd”更新。

三、首次使用
1. 在面板中点击各模型的“打开网页”，在新电脑上分别登录 GLM、DeepSeek、千问、阶跃星辰、腾讯混元，然后返回面板。阶跃使用 https://chat.stepfun.com/chats/new，旧 AI Studio 适配会自动替换。
2. 所有题型统一输入，无需选择题型。自行获取题目，粘贴文字；截图使用 Ctrl+V 粘贴到面板中。
3. 每个 AI 会话仅首题携带统一规则，确认提交成功后，后续只发送题目文字与原图；新会话重新带规则，首题失败重试仍带规则。提示词要求回复正文仅一行纯文本，“答案：”与结果必须同行，不附选项原文、解析、来源、客套话或追问；无法确定时也只用一行“无法确认：简短原因”。核对题目及原图，点击“一键发送”，插件会维护一个 AI 后台窗口，请保持开启。等所有模型实际提交题目或明确失败后，后台每 1.5 秒自动读取未结束模型的本题网页，无需切换 AI 标签页，识别到明确答案就显示，模型回复结束后锁定结果，即使未识别出有效选项也停止该模型轮询，不再读取或切换该模型页面；其他未完成模型继续，全部结束后立即取消轮询和页面切换。重试或下一题会重新采集。完整回复可在卡片中展开“模型原回复”查看。
DeepSeek 读取前会自动滚动聊天区到最新回复，不把展开的思考过程当作答案；捕获完成后停止滚动。
4. 点击“清空 / 下一题”立即清除面板里的文字、图片和结果，同时停止旧题；尚未读完的旧图片不会重新出现。下一题继续使用原会话。发送新题或重试时，也会先停止旧回答，确认网页停止后再发送。发送失败留下旧草稿，或图片在上传中被取消时，会自动刷新该模型的当前会话页面，清理未发送的文字和图片；已发送的聊天记录保留。
5. 新电脑首次使用，先测试文字题、连续两题和实际截图题，再用于正式答题。
6. 模型、思考强度和联网等选项由你在原网页自行设置。插件沿用网页当前设置，只填写题目、上传原图并发送，不打开模型菜单或切换模式。人工补录和手动汇总已移除。

四、迁移范围
- 安装包包含全部插件运行文件、默认五家模型配置和两个在线更新工具脚本。
- 不需要安装Node、Python，不需要 API Key 或本地服务。
- 新电脑需要能正常访问五家 AI 网页并完成登录。
- 旧电脑的 AI 登录状态、本机自定义模型和选择器配置、本题状态不包含在安装包内，也不会由本插件自动同步。自定义设置需在新电脑重新配置。
- 旧网页聊天记录是否能跨电脑查看，由各 AI 网站及登录账号决定。
- 插件依赖 AI 网页控件。新电脑的实际浏览器、网络、图片上传流程需要自行验证；本安装包尚未在另一台电脑上实测。

五、答题规则
默认五家参与投票：汇总实时显示已完成且有效答案中的最高票答案和票数；平票并列显示。无法确认、失败、仍在生成或无法识别的答案不计票。多选按完整组合投票，AC 与 CA 相同，AC 与 ABC 不同。
明确“无法确认”的回复不计票；缺票不会自动触发 GLM 兜底。
提示词要求无法确定时如实说明、不得猜测编造；程序没有独立核验答案事实或来源，不能保证模型绝不编造。
回答正文和答案不写入浏览器缓存。只保留任务编号等控制信息，刷新面板后重新读取本题。
