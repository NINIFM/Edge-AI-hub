并答 · 2.0 使用说明

在 Edge 内运行，不需要 API Key 或常驻本地服务。模型网页需要能正常访问并已登录。

开始使用

  1. 在 Edge 地址栏打开 edge://extensions，开启开发人员模式。
  2. 点击“加载解压缩的扩展”，选择本项目的 extension 文件夹。
  3. 点击扩展图标“并答 · 多模型答题助手”，打开面板。
  4. 点击模型卡片的“打开网页”，自行完成五家登录。首次使用会创建各模型的专用会话，后续题目继续在同一会话中发送。
  5. 所有题型统一输入，无需选择单选、多选或判断。将题目文字或截图粘贴到面板。截图可直接 Ctrl+V。
  6. 核对题目与图片，点击“一键发送”，等所有模型实际提交题目或明确失败后，后台每 1.5 秒读取未结束模型的本题网页，识别到明确答案即显示，并继续检查后续更正；模型回复结束后锁定结果，即使未识别出有效选项也停止该模型轮询，停止读取和切换该模型页面；其他未完成模型继续，全部结束后立即取消轮询和页面切换。重试或下一题会重新采集。识别到有效答案时只显示答案；无法确认或未识别出有效答案时，卡片直接显示模型原回复。

阶跃星辰使用 聊天网页端；旧 AI Studio 适配会自动迁移，已有启用和投票设置保留。

DeepSeek 读取前自动滚动聊天区到最新回复，展开的思考过程不计入答案；捕获完成后停止滚动。

网页设置

模型、思考强度和联网等选项由你在原网页自行设置。插件沿用网页当前设置，只填写题目、上传原图并发送，不打开模型菜单或切换模式。

一键更新

  1. 每台电脑首次双击安装目录中的 更新并答.cmd，启用当前 Windows 用户的本地更新启动入口。
  2. 以后点击面板右上角的 一键更新；Edge 若提示打开本地应用，选择打开。
  3. 工具会从 GitHub 检查、下载并替换原安装文件，失败时保留或恢复原版本。
  4. 完成后在 edge://extensions 点击并答的 重新加载，再刷新面板；下一次发送会自动更新旧版模型网页的适配。

首次从 1.0 升级，需要先将新版文件放入原安装目录，以取得更新按钮和工具。更新前请先结束当前题目。也可以直接双击“更新并答.cmd”更新。

如实作答要求

每个 AI 会话仅首题携带统一答题规则，确认提交成功后，后续只发送题目文字与原图；新会话重新带规则，首题失败重试仍带规则。提示词要求回复正文仅一行纯文本，“答案：”与结果必须同行；选择题只填选项字母，判断题填正确或错误，不附选项原文、解析、来源、客套话或追问。无法确定时也只用一行“无法确认：简短原因”。有可靠依据才输出完整答案；找不到可靠依据或无法确定时必须说明“无法确认”，不得猜测或编造。明确弃答在面板单独标为“无法确认”，不计票；完整回复可在原网页查看。提示词不能保证模型绝不编造；程序没有独立核验模型的事实或来源。

答案汇总

默认 GLM、DeepSeek、千问、阶跃星辰、腾讯混元参与投票。汇总实时显示已完成且有效答案中的最高票答案和票数；平票并列显示。多选按完整组合计票，AC 与 CA 相同，AC 与 ABC 不同。

无法确认、失败、仍在生成或无法识别的答案不计票。自定义新增模型默认只供参考，可在模型设置中启用投票。

网页适配失败时

  • 点击“打开网页”检查登录、网络、限流、验证码和生成状态。这些交互由你自己完成。
  • “重试”在该模型原会话中重发本题原文和原图。原网页仍在生成时，会先点击停止，确认网页停止后再发送。发送失败留下旧草稿，或图片在上传中被取消时，会自动刷新当前会话页面，清理未发送的文字和图片。面板刷新后原题和原图不保留，请重新粘贴。
  • 网页回答已结束但页面没有可识别的结束标志时，面板显示“待确认”。你核对后可确认网页已完成，或重试本模型。
  • “停止本题”会停止发送、收集和各模型网页的当前生成；已经发送到网站的消息不会撤回。
  • 页面改版可在“模型设置”中调整 CSS 选择器或点选校准。新增 AI 不代表已支持自动发送题目和采集回答，仍需配置对应网页控件并逐一测试。

图片题

截图和真正的图形题都发送原图，不先转成 OCR 文字替代。每题 1 张，重新粘贴会替换原图；单张不超过 8 MiB，支持 PNG、JPEG、WEBP、GIF；各网站可能有更低限制。程序检查附件数量与上传状态，无法确认时会报错而不继续发送缺图题。当前网站实际选择的模型能否理解图片，仍取决于其产品能力。

数据与权限

程序仅操作你配置并授权的 AI 网站专用标签页，不读取或操作比赛网页。题目文字、原图在面板和发送流程内存中暂存，不写入本地持久存储；设置保存在本机。回答正文和答案不写入浏览器存储，只在运行内存中用于识别；后台自动采集完整答案，无需逐个切换 AI 网页；可留在面板或继续自行检索。会话存储只保留任务编号、题型和模型页面编号等控制信息，以便面板刷新后重新读取本题网页。“清空 / 下一题”立即清除文字、图片和结果，同时停止旧题；尚未读完的旧图片不会重新出现，各模型保留原会话。继续粘贴下一题后，会在同一会话连续作答。标签关闭、失效或离开该模型授权域名时，才重新创建。

点击发送会把题目与原图传给所选 AI 网站，网站可能按其自身规则保存聊天记录。清空面板不会删除各 AI 网站的聊天记录。

建议先练习

正式比赛前，在同一台电脑和相同网络下，用两道非比赛文字题确认五家在原会话连续作答，再实际 Ctrl+V 截图测试图片、失败重试和下一题。第一版依赖网页控件，网站改版、验证码和后台标签页限速都可能影响自动流程。
