并答 · 1.0 使用说明

在 Edge 内运行，不需要 API Key、VPN 或本地服务。模型网页需要能正常访问并已登录。

开始使用

  1. 在 Edge 地址栏打开 edge://extensions，开启开发人员模式。
  2. 点击“加载解压缩的扩展”，选择本项目的 extension 文件夹。
  3. 点击扩展图标“并答 · 多模型答题助手”，打开面板。
  4. 点击模型卡片的“打开网页”，自行完成四家登录。首次使用会创建各模型的专用会话，后续题目继续在同一会话中发送。
  5. 默认“不限定题型”，接收完整选项组合或正确/错误；如需严格限制格式，可选择单选、多选或判断。将题目文字或截图粘贴到面板。截图可直接 Ctrl+V。
  6. 核对题目与图片，点击“一键发送”，面板每秒直接读取本题网页，识别到明确答案即显示，并继续检查后续更正；模型完成后计入汇总。完整回复点击“打开网页”查看。

如实作答要求

每题使用一行中性提示：有可靠依据才输出完整答案；找不到可靠依据或无法确定时必须说明“无法确认”，不得猜测或编造。明确弃答在面板单独标为“无法确认”，不计票；完整回复可在原网页查看。提示词不能保证模型绝不编造；程序没有独立核验模型的事实或来源。

如何取推荐答案

默认 GLM、DeepSeek、千问、Kimi 参与投票。至少三家的完整答案一致时取一致答案；四家都已完成并提取出明确答案，但没有严格过半时取 GLM。多选题把 AC 与 CA 视为同一组合，不按单个选项拆票。

模型明确无法确认、超时、上传失败、仍在生成和无法识别的答案不投票，也不会悄悄减少投票人数。若完整答案已构成严格过半，可以提前显示推荐；否则显示等待或信息不完整。若需要自行决定，可以查看暂供参考的AI答案。

增加投票模型后按已启用投票模型数量严格过半（例如 4 家需 3 票）。自定义新增模型默认只供参考。此界面统计的是答案一致性，不是正确率或保证提分。

网页适配失败时

  • 点击“打开网页”检查登录、网络、限流、验证码和生成状态。这些交互由你自己完成。
  • “重试”在该模型原会话中重发本题原文和原图。原网页仍在生成时，会先点击停止，确认网页停止后再发送。发送失败留下旧草稿，或图片在上传中被取消时，会自动刷新当前会话页面，清理未发送的文字和图片。面板刷新后原题和原图不保留，请重新粘贴。
  • 网页回答已结束但页面没有可识别的结束标志时，面板显示“待确认”。你核对后可确认或手动录入完整答案。
  • 手动输入 A、AC 或“正确/错误”；判断题不把 A/B 猜测转换为对错。手动覆盖后，该模型后续自动事件不会覆盖你的选择。
  • “停止本题”会停止发送、收集和各模型网页的当前生成；已经发送到网站的消息不会撤回。
  • 页面改版可在“模型设置”中调整 CSS 选择器或点选校准。新增 AI 不代表已支持自动发送题目和采集回答，仍需配置对应网页控件并逐一测试。

图片题

截图和真正的图形题都发送原图，不先转成 OCR 文字替代。最多 4 张，每张 8 MiB，总计 20 MiB，支持 PNG、JPEG、WEBP、GIF；各网站可能有更低限制。程序检查附件数量与上传状态，无法确认时会报错而不继续发送缺图题。当前网站实际选择的模型能否理解图片，仍取决于其产品能力。

数据与权限

程序仅操作你配置并授权的 AI 网站专用标签页，不读取或操作比赛网页。题目文字、原图在面板和发送流程内存中暂存，不写入本地持久存储；设置保存在本机。回答正文和答案不写入浏览器存储，只在运行内存中用于识别；生成过程的正文不逐字同步到面板。会话存储只保留任务编号、题型和模型页面编号等控制信息，以便面板刷新后重新读取本题网页。人工补录答案不保存，后台重启后需重新补录，“清空 / 下一题”会停止各模型当前生成，并清除本题面板与汇总状态，各模型保留原会话。继续粘贴下一题后，会在同一会话连续作答。标签关闭、失效或离开该模型授权域名时，才重新创建。

点击发送会把题目与原图传给所选 AI 网站，网站可能按其自身规则保存聊天记录。清空面板不会删除各 AI 网站的聊天记录。

建议先练习

正式比赛前，在同一台电脑和相同网络下，用两道非比赛文字题确认四家在原会话连续作答，再实际 Ctrl+V 截图测试图片、失败重试和下一题。第一版依赖网页控件，网站改版、验证码和后台标签页限速都可能影响自动流程。
