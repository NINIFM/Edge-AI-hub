# 并答 · 多AI答题助手

面向Microsoft Edge的扩展。手动输入文字或粘贴题目截图，将同一道题发送到多个 AI 网页，收集明确答案并按完整答案投票。

当前版本：**2.0**，网页适配修订：**18**。支持 **GLM、DeepSeek、千问、阶跃星辰、腾讯混元**。

所有题型使用同一输入与发送入口。插件自动维护一个不抢焦点的 AI 后台窗口，等所有模型实际提交题目或明确失败后，每 1.5 秒轮询未结束模型并采集回答。可留在面板或继续检索，无需逐个切换 AI 网页；请保持 AI 后台窗口开启。升级后只需重新加载扩展和刷新面板；下一次发送会自动更新旧版模型网页的适配。

每个 AI 会话仅首题携带统一答题规则；确认提交成功后，后续只发送题目文字与原图。新会话重新带规则，首题失败重试仍带规则。提示词要求回复正文仅一行纯文本：“答案：”与选项字母或判断结果必须同行；禁止选项原文、解析、来源、客套话及追问。无法确定时也只用一行“无法确认”。

DeepSeek 读取前自动滚动聊天区到最新回复，展开的思考过程不计入答案；捕获完成后停止滚动。

各模型独立结束轮询：网页回复结束后，锁定该结果，不再读取或切换该模型页面；其他未完成模型继续，全部结束后停止。重试本模型或开始下一题会重新采集。生成中暂时捕获的答案会继续核对到网页完成。

“清空 / 下一题”立即清除题目文字、图片和面板结果，同时停止旧题；尚未读完的旧图片不会重新出现。

模型、思考强度和联网等选项由用户在原网页自行设置。插件沿用网页当前设置，只填写题目、上传原图并发送，不打开模型菜单或切换模式。

## 下载与安装

从 [最新发布页](https://github.com/NINIFM/edge-answer-hub/releases/latest) 下载 `bingda-edge.zip`。安装包只包含运行文件、更新工具、安装说明和许可证，不包含测试、截图或开发依赖。

1. 将 ZIP 解压到固定目录，保留解压后的文件。
2. 打开 Edge 的 `edge://extensions`，开启开发人员模式。
3. 点击“加载解压缩的扩展”，选择解压目录内的 `extension` 文件夹。
4. 打开扩展面板，分别登录所需的 AI 网页。
5. 输入文字或用 `Ctrl+V` 粘贴截图，点击“一键发送”。

直接使用源码时，加载本仓库的 `extension` 文件夹即可。运行扩展不需要 Node、Python、API Key 或本地服务。详细说明见 [安装说明.txt](./安装说明.txt)。

## 更新

1. 每台电脑首次双击原安装目录中的 **更新并答.cmd**。它为当前 Windows 用户注册并答更新工具的启动入口，并检查最新版本；不需要管理员权限。
2. 以后在扩展面板点击 **一键更新**。Edge 若询问是否打开本地应用，选择打开。
3. 工具自动从本仓库获取版本、下载发布 ZIP、核对内容并替换原安装目录中的文件；当前已是最新版时不会重复下载。
4. 更新完成后，在 `edge://extensions` 点击并答的 **重新加载**，再刷新扩展面板。

首次从 1.0 升级(已下架)，需要将 2.0 发布 ZIP 中的文件放入原安装目录，以取得更新工具和面板按钮；以后由工具在线更新。保持原安装目录，不要将每一版加载成另一份扩展。没有启用启动入口时，也可以直接双击“更新并答.cmd”更新。

工具只使用 Windows 自带的 PowerShell。下载或校验失败时保留原文件，替换失败时恢复已替换的文件。更新前请结束当前题目。模型登录、浏览器本地设置及安装目录中的其他文件不参与替换。

`update.json` 是更新工具查询版本与下载位置所需的配置。它仅指向本仓库的发布 ZIP，更新过程无需 GitHub 登录或令牌。移动整个安装目录后，重新双击“更新并答.cmd”即可更新启动入口。

## 答案规则

- 默认五家参与投票，汇总实时显示已完成且有效答案中的最高票答案和票数；平票并列显示。
- 支持“答案：B.PICO 分析✅”  “正确答案是 D. 广东”  “本题答案为 AC”  “因此选 D”等明确结论及末尾标点；选项说明中的英文字母不计入答案，假设、疑问、冲突或不确定表述不计票。
- 多选按完整组合投票，`AC` 与 `CA` 相同，`AC` 与 `ABC` 不同。
- 明确“无法确认”、失败、仍在生成或无法提取的回复不计票。
- 可以配置其他模型。自定义模型默认只作参考，需要自行适配网页控件和验证发送、读取行为。

## 数据与限制

题目文字和图片通过已登录的模型网页发送，由相应 AI 服务处理。扩展不读取或上传账号密码，不提供自有云端存储；模型配置与必要的任务控制信息保存在浏览器本地。回答正文和答案不写入浏览器持久缓存。

扩展依赖各 AI 网页的结构和控件，网站改版可能需要调整选择器。图片题验证及网页适配不能保证答案正确，正式使用前请在各自电脑上验证文字题、连续题和截图题。

## 源码

`extension/` 包含扩展全部运行代码；没有构建步骤或第三方运行依赖。`manifest.json` 定义权限与入口，`providers.mjs` 定义模型配置，`content.js` 负责网页发送与采集，`controller.mjs` 负责协调，`core.mjs` 负责答案解析和投票，`dashboard.*` 与 `help.html` 提供面板和帮助页。根目录的 `update.ps1` 与“更新并答.cmd”提供本地在线更新工具。
