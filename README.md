# 并答 · 多模型答题助手

面向 Windows / Microsoft Edge 的 Manifest V3 扩展。手动输入文字或粘贴题目截图，将同一道题发送到多个 AI 网页，收集明确答案并按完整答案投票。

当前版本：**1.0**，网页适配修订：**8**。默认支持 **GLM、DeepSeek、千问、Kimi**。

## 下载与安装

从 [最新发布页](https://github.com/NINIFM/edge-answer-hub/releases/latest) 下载发布 ZIP。安装包只包含运行文件、安装说明和许可证，不包含测试、截图或开发依赖。

1. 将 ZIP 解压到固定目录，保留解压后的文件。
2. 打开 Edge 的 `edge://extensions`，开启开发人员模式。
3. 点击“加载解压缩的扩展”，选择解压目录内的 `extension` 文件夹。
4. 打开扩展面板，分别登录所需的 AI 网页。
5. 输入文字或用 `Ctrl+V` 粘贴截图，点击“一键发送”。

直接使用源码时，加载本仓库的 `extension` 文件夹即可。运行扩展不需要 Node、Python、API Key 或本地服务。详细说明见 [安装说明.txt](./安装说明.txt)。

## 更新

当前安装方式是本地加载扩展；**本版本尚未提供扩展内检查更新或自动更新工具**。

下载新版发布 ZIP，使用其中的 `extension` 文件更新原安装目录，在 `edge://extensions` 点击“重新加载”，再刷新扩展面板和模型网页。保持原安装目录，不要将每一版加载成另一份扩展。

GitHub 可以作为版本查询和安装包下载源。若后续增加扩展内更新入口，获取新版与替换本地文件仍是两个步骤；普通扩展不能直接覆盖本地安装目录。

## 答案规则

- 默认四家参与投票，至少三家完整答案相同才形成多数。
- 四家均完成且答案有效、但没有多数时，使用 GLM 答案。
- 多选按完整组合投票，`AC` 与 `CA` 相同，`AC` 与 `ABC` 不同。
- 明确“无法确认”的回复不计票；缺票不会缩小投票分母或自动触发 GLM 兜底。
- 可以配置其他模型。自定义模型默认只作参考，需要自行适配网页控件和验证发送、读取行为。

## 数据与限制

题目文字和图片通过已登录的模型网页发送，由相应 AI 服务处理。扩展不读取或上传账号密码，不提供自有云端存储；模型配置与必要的任务控制信息保存在浏览器本地。回答正文和答案不写入浏览器持久缓存，人工补录答案在后台重启后需重新补录。

扩展依赖各 AI 网页的结构和控件，网站改版可能需要调整选择器。图片题验证及网页适配不能保证答案正确，正式使用前请在各自电脑上验证文字题、连续题和截图题。

## 源码

`extension/` 包含扩展全部运行代码；没有构建步骤或第三方运行依赖。`manifest.json` 定义权限与入口，`providers.mjs` 定义模型配置，`content.js` 负责网页发送与采集，`controller.mjs` 负责协调，`core.mjs` 负责答案解析和投票，`dashboard.*` 与 `help.html` 提供面板和帮助页。
